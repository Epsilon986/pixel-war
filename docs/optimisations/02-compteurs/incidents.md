# Incidents de pilotage de la campagne 02

- Le premier lancement Maven sous sandbox a échoué avant le démarrage des tests : erreur PowerShell du wrapper (indexation d'un tableau Null, Cannot start maven from wrapper). L'exécution autorisée hors sandbox a réussi avec 70 tests. Le même chemin tests-initial.log a été réutilisé : son contenu est celui du succès ; la sortie du premier échec n'est pas conservée comme log brut séparé. Il ne s'agit pas d'un échec métier ni d'une régression des compteurs.
- La branche du dossier principal est repassée de opti/02-compteurs à refacto_metriques pendant les essais applicatifs. Un worktree isolé a été créé dans target/opti-02/worktree. Les JVM et sources reconstruites dans results/builds/baseline/source proviennent du commit c5a8777 et ne dépendent pas de cette branche active. Les données mesurées n'ont pas été remplacées. L'analyse finale est reprise depuis le worktree avec -Resume.
- Le pilote de livraison place le début du chronomètre mural après le retour de resume. La campagne initiale utilisait le pilote du commit c5a8777, avec début juste avant resume. Les durées actives exactes conservées dans les relevés sont contrôlées à au moins 20 secondes, indépendamment de cette enveloppe murale. Ce changement concerne le banc, pas la production.
- Le dernier appel automatique d'analyse a échoué car le checkout du dossier principal avait retiré scripts/opti02/analyze.py de cet emplacement. Les 63 observations et JFR étaient terminés. La reprise depuis le worktree avec -Resume a effectué les exports et la synthèse sans refaire les mesures.
- Une première commande de reprise contenait une référence Git mal recopiée (c5a8777bd), rejetée avant essai. La reprise avec c5a8777 a réussi. Les invocations conservent cette erreur de pilotage ; aucune référence ni observation n'a été substituée.
- Les six fenêtres SMALL applicatives finissent avec trois joueurs éliminés. Le survivant continue des poses alliées sans changement. Les taux de tentatives bruts sont conservés comme tels mais ne représentent pas une capacité utile de guerre territoriale. Les débits de modifications/conversions et les états d'élimination sont distincts ; aucun gain n'est inféré de ces fenêtres. Le banc ne capture pas l'heure exacte du dernier affrontement.
